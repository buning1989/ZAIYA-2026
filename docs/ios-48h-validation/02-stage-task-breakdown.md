# 在呀 ZÀIYA｜任务拆解、优先级与用户关注重点

## 优先级

### P0

独立工程、模拟器、真机、导航、键盘、真实 AI、SQLite、记录到回看、强退恢复、稳定性。

### P1

基础字号、间距、按钮反馈、空状态、loading、一个普通角色动画和 AI 行动卡片。

### P2

语音、流式 AI、多种记录、趋势图、透明视频、Rive、登录、云同步、Widget、Watch、轻社交、能量和全量 Web 迁移。

## 任务顺序

### 1. 独立工程｜0～2 小时

TRAE：创建 `spike/ios-48h`、`ios-app/`、Expo 工程和首次提交。

用户关注：

- 是否与 Web 隔离；
- 是否擅自重构 Web；
- 是否建立 monorepo；
- 新增依赖是否过多。

为什么：验证失败后必须能无损停止，Web 仍是比赛兜底。

### 2. 模拟器与真机｜2～10 小时

TRAE：模拟器、Personal Team 签名、真机安装、前后台、强退、停止 Metro 后测试。

用户关注：

- 不看页面好不好看；
- 必须亲自在 iPhone 上启动；
- 有无白屏、黑屏、闪退；
- 断开调试后是否运行。

为什么：真机装不上，后续所有业务开发都没有意义。

### 3. 四页导航｜最晚 12 小时

用户亲测：

```text
首页 → 对话 → 首页
首页 → 睡眠记录 → 首页
首页 → 回看 → 首页
对话 → 睡眠记录 → 回看
```

关注返回是否意外退出、卡死或堆叠错误。

为什么：导航基础错误在加入键盘和数据后更难修。

### 4. 对话交互壳｜10～18 小时

用户重点关注：

- 键盘是否遮挡；
- 页面是否跳动；
- 连续 10 条消息；
- 自动滚动；
- 长回复；
- 返回后会话是否在。

为什么：在呀的核心交互是对话，键盘和列表不可控则路线不成立。

### 5. 真实 AI｜18～28 小时

用户审核三类：

- 普通：理解处境，不直接说教；
- 边界：不诊断、不停药、不调药；
- 高风险：严肃处理，不继续普通陪聊或只建议呼吸。

同时检查 10 次至少 9 次成功、断网恢复、密钥只在服务端。

为什么：技术返回不等于产品成立，安全边界和现实行动连接才是重点。

### 6. SQLite｜28～34 小时

用户亲自执行：

```text
创建记录 → 回看 → 强退 → 重启 → 回看
```

关注是否真持久化、是否重复、是否误用 Mock。

为什么：普通页面返回不等于数据保存。

### 7. 睡眠记录｜最晚 36 小时

只保留日期、入睡、起床、感受、补充。

用户关注：

- 是否足够轻；
- 跨午夜是否正确；
- 保存反馈；
- 连点是否重复保存。

测试：

```text
01:30 → 08:00 = 6 小时 30 分钟
23:30 → 07:00 = 7 小时 30 分钟
```

为什么：验证 AI 能否连接现实生活事实，不是迁移完整记录系统。

### 8. 回看｜34～38 小时

用户关注：

- 是否是刚生成的真实数据；
- 字段是否一致；
- 保存后立即刷新；
- 强退后仍存在；
- 不使用 Mock。

为什么：回看是“生活被看见”的直接证据。

### 9. 完整闭环｜36～42 小时

用户判断：

- 是否仍只是普通聊天 App；
- 是否完成“模糊困扰→小行动→记录→回看”；
- 是否存在多余步骤；
- 是否临时增加功能。

为什么：在呀的终点是生活功能改善，不是陪聊本身。

### 10. 基础质感｜38～42 小时

只改影响使用的问题：贴边、字小、按钮不清楚、loading 无反馈、动画拉伸、页面跳动、返回不清楚。

不做逐像素还原和复杂动效。

为什么：先判断原生路线可控，再谈最终视觉上限。

### 11. 稳定性｜42～46 小时

用户至少亲测一轮，关注的不只是闪退，还包括按钮偶尔失效、页面变慢、键盘错位、网络恢复失败、数据重复、视频黑屏、返回偶发异常。

为什么：比赛现场更常见的是“页面还在，但无法继续”。

### 12. 录屏与判定｜46～48 小时

必须一镜到底，不接受多个局部片段，不接受“基本可行”。最终只能 `GREEN / YELLOW / RED`。

## 用户介入节点

| 时间 | 用户检查 | 决策 |
|---|---|---|
| 2 小时 | 工程隔离、依赖 | 是否继续 |
| 6 小时 | 模拟器、导航 | 工程基础 |
| 10 小时 | 真机安装 | 未通过则暂停 |
| 18 小时 | 键盘和滚动 | 对话是否可控 |
| 28 小时 | AI 与安全 | AI 是否可用 |
| 36 小时 | 强退恢复 | 数据闭环 |
| 42 小时 | 产品路径 | 是否体现核心价值 |
| 46 小时 | 稳定性 | 是否可供评委体验 |
| 48 小时 | 录屏与证据 | 红黄绿决策 |

用户关注顺序：真机 → 键盘导航 → AI安全 → 数据 → 完整闭环 → 稳定性 → 视觉。
